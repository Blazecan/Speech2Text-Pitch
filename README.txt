Speech2Text-Pitch (NAME W.I.P.)

Speech2Text-Pitch is a program that takes your microphone input and records it
as text spoke with the associated pitch over time. 

Currently this is cool tool with a visualizer, but will eventually have 
corresponding plugins for DAWs and other applications. 

SETUP

Download the requirements file to a virtual environment
First: python3 -m venv .venv
Second: pip install -r requirements.txt

Check the requirements.txt file for instructions on downloading the correct
version of pytorch if you are using CUDA. 

First time this program runs it will downlaod the speech to text model, 
so you must be connected to the internet

It is currently setup to use CUDA with 6GB VRAM or greater
If 4GB or less, go to transcriber.py and change MODEL_SIZE = "large-v3" to "medium"
If using CPU instead of CUDA, its recommended ot use MODEL_SIZE = "small"

Currently setup to only recognize english text. To recognize other languages,
go to transcriber.py and in _run_inference() change "en" to NONE for automatic
detection or any other language 

Instructions on how to run main.py, check the top of the file or run main.py -h

EXAMPLE
After starting the virutal environment, run 
(Your file path)/main.py --transport file
Once everything is loaded, Sing/speak into your microphone.
When finished, press Ctrl + C to exit the program. 

Then, use the included visualizer by running 
(Your file path)/pitch_visualizer.py pipeline_output.log
